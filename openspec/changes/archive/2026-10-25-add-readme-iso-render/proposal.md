## Why

The README describes the jack in words only. A reader has to open the STEP file in KiCad
or a CAD viewer to see what the model looks like. A coloured isometric image at the top of
the README shows the black housing, gold shell and gold leads at a glance. The build's
current `--preview` option only writes monochrome SVG line projections to the gitignored
`build/` directory, so it can't serve this purpose.

## What Changes

- Add a matplotlib renderer that draws the model in an isometric view. It tessellates the
  housing, the front shell and the six leads separately and fills each part with its STEP
  colour from `params.py` (near-black housing, gold shell and leads), with simple flat
  shading so the faces read as 3D.
- Add a `--render` option to `pj3106m-build` that writes the image to the committed path
  `docs/PJ-3106M_iso.png`. The default build (STEP + STL) stays the same.
- Commit the generated PNG and embed it near the top of `README.md`. Document the
  regenerate command in "Build and test", and add `docs/` to the "Layout" section.
- Declare `matplotlib` as an explicit project dependency. It's already in `uv.lock`
  transitively (cadquery → vtk), so the locked versions don't change.
- Add a test that renders to a temp directory and checks the result is a non-empty PNG of
  the expected size that contains both housing-like dark pixels and gold pixels.

Non-goals: photorealistic rendering (no ray tracing, textures or smooth shading), extra
views or animations, and a byte-for-byte staleness check for the PNG. Matplotlib/Agg output
can differ slightly between versions and platforms, so the PNG isn't held to the same
"committed output is current" test as STEP/STL.

## Capabilities

### New Capabilities
- `model-preview-image`: a coloured isometric PNG of the model, generated by the build
  with matplotlib, committed under `docs/` and shown in the README.

### Modified Capabilities
- `dev-environment`: the "Developer documentation" requirement now also covers the README
  showing the rendered model image and the command that regenerates it.

## Impact

- Code: new `src/pj3106m_model/render.py`; `src/pj3106m_model/build.py` gets a `--render`
  flag.
- Tests: new `tests/test_render.py`.
- Dependencies: `matplotlib` added to `[project].dependencies` in `pyproject.toml`, and
  `uv.lock` updated (only the root package's dependency list changes).
- Docs/assets: new committed `docs/PJ-3106M_iso.png`; `README.md` gets the image, the build
  command and a layout entry.
- No change to the geometry, the STEP/STL outputs or the coordinate frame.
